# Offene Entscheidungen
| Thema | Stand / Auswirkung |
|---|---|
| Fotoanzahl | **10.000 je Album**, durch Nutzerauskunft bestätigt; 100 aus Lehrbeispielen wird nicht übernommen. |
| Dateigröße | 50 MB laut Anforderungen; dezimale/binäre Auslegung vor Implementierung bestätigen. |
| Formate | Nicht festgelegt; vor produktivem Import Positivliste vereinbaren. |
| Titel/Beschreibung | Maximalwerte offen, keine 100/255/1000-Zeichen-Grenze erfinden. |
| Zeichen zählen | Entwurfsannahme: Unicode-Codepoints; fachlich bei Teamreview bestätigen. |
| Datum | Aufnahmedatum vs. Importdatum, fehlendes EXIF und Zeitzone klären. |
| Papierkorb | Aufbewahrung, Wiederherstellen, einzelne Fotos und endgültiges Löschen konkretisieren. |
| Plattformen | NFA-04 verlangt Geräte- und Web-App; Swing erfüllt allein nur Geräte-UI. Adaptergrenze ermöglicht spätere UI, liefert sie noch nicht. |
| Teilen | FA-09 verlangt Einladungen/Link; Sicherheits-, Server- und Identitätskonzept fehlen. Eigene Entscheidung vor Umsetzung nötig. |
| Lieferumfang | MoSCoW für Sortieren/Teilen/Web im Team klären; bestehende Muss-Anforderungen werden nicht zu Won’t umgedeutet. |
